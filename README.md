# BÀI THỰC HÀNH 2 Microsoft Word - Trộn thư và tạo mục lục và Google Docs

## Nội dung thực hành
## Phần 1
- **Trộn thư dữ liệu từ Excel**
  - Tạo cơ sở dữ liệu bằng Excel.
  - Tạo tập tin chính bằng Word.
  - Thực hiện trộn thư và xuất kết quả.
## Phần 2
- **Tạo mục lục bằng Microsoft Word**
  - Nhập nội dung tài liệu.
  - Tạo và định dạng Heading 1, Heading 2, Heading 3.
  - Tạo mục lục tự động.
  - Tạo danh mục hình, bảng và đồ thị.

- **Tạo Caption và trích dẫn**
  - Tạo nhãn Hình và Bảng.
  - Đánh số Caption theo chương.
  - Tạo và chèn trích dẫn theo chuẩn IEEE.
  - Tạo tài liệu tham khảo.
##  Phần 3
- **Google Docs**
  - Chia sẻ tài liệu.
  - Thiết lập quyền Editor, Viewer, Commenter.
  - Sử dụng Meeting và History.

## Công cụ sử dụng

- Microsoft Word
- Microsoft Excel
- Google Docs
- GitHub
